Error Type Taxonomy

Every discrepancy maps to exactly one bucket. Each bucket has a fixed severity and a specific recommended action — not a generic flag.

CRITICAL_TERMINATED_PAID
Employee status = Terminated in HRIS, but Gross_Pay > 0 in Payroll. Money left the bank for someone who no longer works here.
Initiate recovery
ORPHAN_PAYROLL_RECORD
Employee_ID exists in Payroll but has no matching record in HRIS at all. Could be a ghost employee or a data entry error.
Fraud escalation
BASE_RATE_MISMATCH
HRIS Base_Salary ≠ Payroll Base_Salary. Either an increment was approved in HRIS but not reflected in payroll, or payroll was manually edited.
Check increment letter
OFF_CYCLE_MANUAL_ADJ
Payment_Mode = Manual_Adjustment with no corresponding HRIS approval record. Common for ad-hoc bonuses or corrections processed outside the normal run.
Get retroactive approval
GL_NET_MISMATCH
GL_Amount_Posted ≠ Payroll Net_Pay for the same Employee_ID and Pay_Period. What was computed vs what was booked in finance don't agree.
Correction journal entry
ESI_BOUNDARY_RISK
Employee's gross is between ₹18,000–₹21,000. Overtime this month may push them past the ESI eligibility threshold of ₹21,000, changing their deduction profile next month.
Monitor next cycle
OT_ANOMALY (Z-score)
Overtime or allowance component deviates >2.5 standard deviations from the department mean. Catches spikes hardcoded rules miss — a ₹200 intern spike is anomalous; a ₹2,000 senior doctor spike is normal.
Review shift roster

Indian Statutory Compliance Checks

PF / EPF
12% employee + 12% employer on basic, capped at ₹15,000 wage. Verify UAN mapping and that PF_Deduction matches the formula exactly.
PF reconciliation
Professional Tax (Karnataka)
₹200/month above ₹15,000 gross. Multi-location hospitals may incorrectly apply another state's slab when merging branch data.
Slab check
TDS (Old vs New Regime)
Employee declarations change which slab applies. If the regime flag in HRIS differs from payroll's assumption, TDS will be wrong across the full year.
Declaration audit

Build Sequence — Do Not Skip Steps

✓
mock_generator.py
Three CSVs with 5 injected errors. Reproducible with --seed.
2
validator.py
Pydantic schema contracts. Bad files quarantined, never ingested. Pipeline never crashes.
3
ingestion.py
MD5 hash check. Idempotent — drop same file twice, get no duplicate rows. Loads DuckDB tables.
4
reconciliation.py
FULL OUTER JOIN across all three tables. Every row gets one of the 7 error bucket labels. Show to AGM before building UI.
5
insight_engine.py
Z-score anomaly detection on OT/allowances. Cost pattern analysis. Recommended action per error type.
6
app.py (Streamlit)
4 pages: Overview · Mismatch Drilldown · Cost Intelligence · Audit Trail. Mark-resolved workflow. Export buttons.
7
tests + README + GitHub
pytest for validator and reconciliation. README with architecture diagram. Then stop — ship it.
